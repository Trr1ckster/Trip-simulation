# CAR_route

Расчёт маршрута автомобиля по GPS-треку: восстановление пропущенных точек, уклон, скорость,
время в пути и расход топлива. Есть интерактивное Streamlit-приложение — анимированная карта
и четыре синхронных графика.

Модель считает две вещи: силу сопротивления движению по скорости и уклону, и расход топлива
по этой силе. Плюс простое правило движения — ехать медленнее на подъёме, быстрее на спуске
и немного разгоняться перед горкой.

## Данные

`route_with_losses.csv` — трек на 3864 точки (818 км). У 471 строки (12.2 %, 18 участков) пустые
`longitude`, `latitude` и `altitude`: номера строк известны, а значения в них потеряны —
их и нужно восстановить.

`route.csv` — исходный маршрурт без потерь.

## Как это работает

### 1. Восстановление пропусков

Координаты восстанавливаются линейно по номеру точки (точки кладутся на хорду между
сохранившимися границами разрыва):

$$
y_i = y_a + \frac{i - a}{b - a}\,(y_b - y_a), \qquad i \in [a, b]
$$

где $a$ и $b$ — индексы граничных сохранившихся точек, $y$ — `longitude` или `latitude`.

Высота восстанавливается монотонным кубическим сплайном PCHIP (scipy), который проходит через все
известные точки и не «выстреливает» между ними:

$$
h_i = \mathrm{PCHIP}(\{(x_j, h_j)\}_{j \in \text{known}})(x_i)
$$

Число точек и их порядок не меняются, экстраполяции нет.

### 2. Расстояние и уклон

Расстояние между точками — геодезическое (`geopy`, WGS84), накапливается в `dist_km`.
Уклон считается не по соседним точкам, а по окну $\pm 150$ м, чтобы убрать шум высоты —
как среднее двух наклонов на краях окна:

$$
\theta_i = \frac{1}{2}\left(
\frac{h(s_i) - h(s_i - \Delta)}{\Delta} +
\frac{h(s_i + \Delta) - h(s_i)}{\Delta}
\right) \cdot 100\,\%,
\qquad \Delta = 150\ \text{м}
$$

Высоты перед этим сглаживаются скользящим средним по 7 точкам, уклон — окном 5 точек.

### 3. Сопротивление движению

$$
F(v, \alpha) = mg\,C_r \cos\alpha + mg \sin\alpha + \tfrac{1}{2}\rho\,C_d A\,v^2
$$

Слагаемые по порядку: качение, подъём, аэродинамика. Здесь $m = 1700$ кг, $C_r = 0.012$,
$\rho = 1.225$ кг/м³, $C_dA = 0.65$ м², $\alpha = \arctan(\text{уклон})$.
На спуске $F < 0$ — машину ведёт гравитация.

### 4. Расход топлива

Мощность на колёсах $P = F \cdot v$ делится на КПД двигателя при этой нагрузке — столько мощности
затрачивается на тягу; деление на теплоту сгорания литра даёт литры в час, а на 100 км — то же,
делённое на скорость. Отдельно добавляется расход на холостом ходу:

$$
q(v, \theta) = \frac{P(v,\theta) / \eta(P)}{Q_л} \cdot \frac{100}{v}
+ \frac{q_{хх}}{v} \cdot 100, \qquad
Q_л = 42.7\ \frac{\text{МДж}}{\text{кг}} \cdot 0.75\ \frac{\text{кг}}{\text{л}} \approx 32\ \frac{\text{МДж}}{\text{л}}
$$

где $q$ — расход в л/100км, а расход на холостом ходу равен 1.0 л/ч при движении
($F > 0$) и 0.1 л/ч при торможении двигателем ($F \le 0$, режим ПХХ).

**КПД двигателя зависит от нагрузки** и берётся из паспортной кривой удельного расхода
(BSFC, г/кВт·ч) для бензинового двигателя 1.6 л:

$$
\eta(P) = \frac{3.6\ \text{МДж/ч}}{\mathrm{BSFC}(P) \cdot 42.7\ \text{МДж/кг}}
$$

где $P$ — мощность, снимаемая с двигателя (кВт), а удельный расход берётся из паспортной кривой:

| $P$, кВт | 0 | 10 | 20 | 35 | 60 | 100 |
|---|---|---|---|---|---|---|
| BSFC, г/кВт·ч | 460 | 340 | 275 | 250 | 265 | 300 |

Получается $\eta(4) = 0.21$, $\eta(14) = 0.27$, $\eta(35) = 0.34$:
на малой нагрузке двигатель неэкономичен, максимум КПД — на средней.

Интегрирование по маршруту (трапеции):

$$
\Delta q_i = \frac{q_i + q_{i-1}}{2} \cdot \frac{\Delta s_i}{10^5}, \qquad
\Delta t_i = \frac{\Delta s_i}{\tfrac{1}{2}(v_i + v_{i-1})}
$$

### 5. Скорость

Целевая скорость падает на подъёме и растёт на спуске, держится в границах 30…130 км/ч:

$$
v_{цель} = \mathrm{clip}(100 - 3\,\theta,\ 30,\ 130)
$$

Перед подъёмом скорость добавляется заранее: если в окне 400 м впереди есть уклон круче 3 %,
а текущий уклон ещё не больше 3 %, цель умножается на 1.10.

Фактический профиль ограничен физикой движения:

$$
v_i = \min\left(\sqrt{v_{i-1}^2 + 2a\,\Delta s_i},\ v_{цель}\right),
\qquad
a_{разгон} \le 1.2\ \text{м/с}^2,\quad a_{торм} \le 2.0\ \text{м/с}^2
$$

Прямой проход даёт разгон и свободный накат, обратный — подвод к ограничению торможением
(без него профиль был бы физически нереализуем).

### 6. Оптимальная скорость

Это та же формула расхода, минимизированная по сетке скоростей: для каждой точки перебираются
скорости 30…130 км/ч с шагом 2 и берётся та, при которой расход минимален (быстрее текущей
целевой скорости ехать нельзя, такие варианты отбрасываются):

$$
v_{\text{opt}} = \arg\min_{v \le v_{\text{цель}}} q(v, \theta)
$$

Никаких отдельных допущений для этой линии нет — тот же КПД по нагрузке, что и в расходе поездки.
На ровной дороге минимум получается около **54 км/ч** (кривая плоская: от 50 до 60 км/ч расход
отличается на 0.02 л/100км), по маршруту средняя оптимальная скорость 61.8 км/ч.

## Требования

* Python 3.13
* Зависимости: `streamlit`, `pandas`, `numpy`, `plotly`, `pydeck`, `geopy`, `scipy`

```bash
py -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt   # Windows
.venv/bin/python -m pip install -r requirements.txt           # Linux/macOS
```

## Запуск

```bash
# приложение (анимация, карта, графики) — http://localhost:8501
.venv/Scripts/python.exe -m streamlit run app.py

# восстановление маршрута в CSV
.venv/Scripts/python.exe restore_route.py          # → route_restored.csv
```

### Docker

```powershell
docker compose up --build                          # приложение на http://localhost:8501
docker compose run --rm app python restore_route.py out
docker compose down
```

Порт задаётся переменной: `$env:PORT=8600; docker compose up`.

## Структура

| Файл | Назначение |
|---|---|
| `calculations.py` | восстановление пропусков, уклон, скорость, расход — вся модель |
| `constants.py` | параметры модели (масса, аэродинамика, КПД, ограничения, окна) |
| `charts.py` | четыре графика Plotly |
| `app.py` | Streamlit-приложение: карта pydeck, анимация, метрики |
| `restore_route.py` | восстановление маршрута в `route_restored.csv` |
| `route_with_losses.csv` | вход: трек с пропущенными точками |
| `route_restored.csv` | выход `restore_route.py` (создаётся при запуске) |

## Ограничения

* Квазистационарная модель: силы считаются установившимися, отдельного члена $ma$ в расходе нет.
* КПД задан кривой удельного расхода для двигателя 1.6 л; модели передач и оборотов нет,
  рекуперации нет (бензиновый автомобиль).
* Нет трафика, дорожных ограничений, погоды и ветра; плотность воздуха постоянна.
* Повороты не ограничивают скорость.
